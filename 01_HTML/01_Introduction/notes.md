# HTML Introduction

## 1. What is HTML?
HTML stands for **HyperText Markup Language**. It is the standard markup language used to create and structure web pages.

## 2. Why is HTML Used?
- To create the structure of websites.
- To display text, images and videos.
- To create links between web pages.
- To build forms and tables.

## 3. Features of HTML
- Easy to learn and understand.
- Platform independent.
- Uses tags and elements.
- Works with CSS and JavaScript.
- Supported by all major web browsers.

## 4. Basic HTML Document Structure

An HTML document follows a standard structure:

- `<!DOCTYPE html>` – Declares the HTML5 document.
- `<html>` – Root element of the webpage.
- `<head>` – Contains page information.
- `<title>` – Sets the browser tab title.
- `<body>` – Contains visible webpage content.

## 5. What are HTML Tags?
HTML tags are keywords enclosed in angle brackets that define elements on a webpage.

Examples:
- `<h1>` – Heading.
- `<p>` – Paragraph.
- `<img>` – Image.
- `<a>` – Hyperlink.

## 6. Types of HTML Elements

**Paired Elements:** Have opening and closing tags.

Example: `<p>Hello World</p>`

**Void Elements:** Do not require closing tags.

Examples: `<br>`, `<hr>`, `<img>`

## 7. Role of HTML, CSS and JavaScript

- **HTML:** Provides the structure of a webpage.
- **CSS:** Controls the design and appearance.
- **JavaScript:** Adds functionality and interactivity.

## 8. Important Points to Remember
- HTML is not a programming language; it is a markup language.
- HTML5 is the latest major HTML standard.
- HTML files generally use the `.html` extension.
- HTML code can be written using VS Code or other text editors.

- Meaning and purpose of HTML.
