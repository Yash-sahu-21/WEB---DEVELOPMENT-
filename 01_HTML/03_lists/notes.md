# HTML Lists

HTML Lists are used to display a collection of related items in an organized way.

HTML provides three types of lists:

### 1. Ordered List (`<ol>`)
- Displays items in a numbered or sequential order.
- Uses the `<ol>` tag.
- Each item is written inside the `<li>` tag.
- Types include numbers, uppercase letters, lowercase letters, and Roman numerals.

### 2. Unordered List (`<ul>`)
- Displays items using bullet points.
- Uses the `<ul>` tag.
- Each item is written inside the `<li>` tag.
- Bullet styles include disc, circle, and square.

### 3. Description List (`<dl>`)
- Displays terms along with their descriptions.
- Uses three tags:
  - `<dl>` – Defines the description list.
  - `<dt>` – Defines the term.
  - `<dd>` – Defines the description.

### Additional Concepts
- **Nested List:** A list inside another list.
- **`type` Attribute:** Specifies the numbering or bullet style (mainly in older HTML examples).
- **`start` Attribute:** Specifies the starting number of an ordered list.

**Note:** CSS can be used to customize list styles, bullets, spacing, and alignment.
